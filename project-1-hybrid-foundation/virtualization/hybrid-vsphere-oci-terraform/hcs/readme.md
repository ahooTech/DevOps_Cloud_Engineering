🎯 The Truth About HCS and How to Make it "Real & Free"
First, a crucial distinction for your interviews:
HCS (Huawei Cloud Stack) is the private, on-premises version of Huawei Cloud sold to massive enterprises and Telcos (like Safaricom). You cannot get a free tier for HCS because it requires an enterprise contract and physical hardware.
Huawei Cloud (Public) is the public cloud equivalent (like AWS/GCP). This DOES have a free tier!
To make this "as real as possible for free", we will use the official Huawei Cloud Terraform provider to deploy a real ECS (Elastic Cloud Server) in the Huawei Cloud Public Free Tier.
